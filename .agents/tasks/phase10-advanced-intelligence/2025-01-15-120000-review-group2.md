## NegBin parameterization is correct

The shot production calculator implements distribution fitting in `_fit_distribution()`. For overdispersed data (variance > mean), it selects Negative Binomial and calculates parameters:

```python
r = (mu ** 2) / (variance - mu)
p = r / (r + mu)  # scipy parameterization
```

scipy.stats.nbinom(n, p) uses the "number of failures" parameterization where n (called r in this code) is the number of successes before stopping, p is the probability of success, and the random variable represents the number of failures.

For a Negative Binomial with mean μ and dispersion r:
- Mean = r(1-p)/p
- Solving: μ = r(1-p)/p → μp = r - rp → p(μ+r) = r → p = r/(r+μ)

The implementation's formula `p = r/(r+μ)` is correct for scipy. Verified by test_shot_production.py test_negbin_parameters which validates the parameter relationship and confirms probabilities are valid.

Note: The design document specifies `p = μ/σ²` which is a different NegBin parameterization convention (not scipy's). The implementation correctly adapted this to scipy's expected parameterization.

## Distribution selection correctness

shot_production.py _fit_distribution method (lines 239-275) implements distribution selection:

```python
if variance > mu and variance > mu + 0.5:  # Overdispersed (with buffer)
    # Negative Binomial
    r = (mu ** 2) / (variance - mu)
    p = r / (r + mu)
    ...
else:
    # Poisson (equidispersed or underdispersed)
    return ("poisson", mu, variance, None, None)
```

The selection logic (variance > mean → NegBin) is correct. The 0.5 buffer prevents selecting NegBin for trivially small overdispersion. Parameter validation (r > 0, 0 < p < 1) is present at line 269.

test_shot_production.py test_poisson_selection and test_negbin_selection verify the selection logic works correctly for equidispersed and overdispersed data.
